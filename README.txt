Implementation of Fruit_Ninja using raylib for level 1 term 1.

Authors: Mustaeen - 2505097, Ruhan - 2505119

## To compile and run the project:

- Extract the FRUIT_NINJA.zip file
- *[Optional]:* If a custom raylib configuration is set-up for the windows system,
  then copy the system's custom configured .vscode/ and raylib/ folders
- Open the Fruit_Ninja_Game.c file with *Visual Studio Code*
- Press F5 to compile and run the game


N.B.: The developers are Windows users, so some issues with
macOS and Linux systems may persist, although no compilation issues were found
before deployment of the codebase.
